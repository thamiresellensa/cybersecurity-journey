# 🔐 Desenvolvimento Seguro e Application Security (AppSec)

Diretório central para o objetivo profissional da minha jornada: **Application Security (AppSec)**. Reúne estudos sobre como identificar, prevenir e corrigir vulnerabilidades no ciclo de vida de desenvolvimento de software (SSDLC).

## 📌 Tópicos de Estudo

- Fundamentos de Segurança Web (HTTP, sessões, cookies, CORS, CSP)
- **OWASP Top 10** (Injeções, XSS, Broken Access Control, SSRF, etc.)
- Práticas de *Secure Coding* (validação de entrada, sanitização, tratamento seguro de erros e senhas)
- Análise de código e revisão de segurança (SAST / DAST / SCA)
- Modelagem de Ameaças (*Threat Modeling*)

## 📂 Estrutura

- `owasp/` — Estudos e resumos sobre as categorias do OWASP Top 10
- `secure-coding/` — Exemplos comparativos de código vulnerável vs. código seguro
- `labs/` — Anotações de laboratórios práticos de segurança de aplicações
