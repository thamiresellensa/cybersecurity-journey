# 🐧 Linux e Sistemas Operacionais

Diretório dedicado aos estudos de Linux, linha de comando (Bash), administração de sistemas e conceitos de sistemas operacionais aplicados à segurança.

## 📌 Tópicos de Estudo

- Navegação e manipulação de arquivos no terminal
- Permissões de arquivos e usuários (`chmod`, `chown`, SUID/SGID)
- Gerenciamento de processos e serviços
- Variáveis de ambiente e scripts em Bash
- Logs do sistema e auditoria básica

## 📂 Estrutura

- `notes/` — Anotações teóricas e resumos de comandos
- `scripts/` — Scripts em Bash desenvolvidos durante os estudos
- `exercises/` — Práticas e desafios de terminal
