# ⚡ Programação Competitiva e C++

Diretório dedicado à prática de lógica de programação, algoritmos, estruturas de dados em C++ (com foco no **Codeforces**) e conceitos de baixo nível relevantes para segurança de software.

## 📌 Por que C++ e Programação Competitiva na jornada de AppSec?

- **Raciocínio algorítmico**: Resolução eficiente de problemas complexos e análise de casos de borda (*edge cases*).
- **Compreensão de baixo nível**: Entendimento de gerenciamento de memória, ponteiros e tipos de dados, base essencial para compreender vulnerabilidades clássicas como *Buffer Overflow*, *Integer Overflow* e *Use-After-Free*.

## 📂 Estrutura

- `codeforces/` — Resoluções de problemas do Codeforces organizadas por tema ou dificuldade
- `notes/` — Anotações sobre algoritmos, estruturas de dados e particularidades do C++
