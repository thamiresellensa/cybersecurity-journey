# 🌐 Redes de Computadores (Networking)

Diretório dedicado aos estudos de arquitetura de redes, protocolos de comunicação e análise de tráfego, fundamentais para compreender como aplicações se comunicam e onde ocorrem vulnerabilidades de rede e web.

## 📌 Tópicos de Estudo

- Modelos OSI e TCP/IP
- Endereçamento IP, sub-redes e roteamento
- Protocolos essenciais: TCP, UDP, DNS, HTTP/HTTPS, TLS/SSL
- Diagnóstico e análise de pacotes (`ping`, `traceroute`, `netstat`, `ss`, `curl`, Wireshark)

## 📂 Estrutura

- `notes/` — Resumos sobre protocolos, camadas e funcionamento de redes
- `labs/` — Práticas de análise de tráfego e diagnóstico de rede
