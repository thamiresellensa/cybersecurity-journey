# 🐍 Python

Diretório dedicado ao aprendizado de Python, desde os fundamentos da linguagem até a criação de scripts para automação e segurança da informação.

## 📌 Tópicos de Estudo

- Sintaxe base, estruturas de dados e funções
- Manipulação de arquivos, textos e expressões regulares
- Requisições HTTP e consumo de APIs (`requests`)
- Automação de tarefas e scripts aplicados à segurança

## 📂 Estrutura

- `fundamentals/` — Exercícios e práticas dos conceitos base da linguagem
- `scripts/` — Pequenos scripts utilitários e de automação
